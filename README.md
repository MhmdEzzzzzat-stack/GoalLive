# GoalLive — واجهة مباريات كرة القدم العربية

واجهة أولية احترافية داكنة باتجاه RTL، متجاوبة مع الهاتف، مع مباريات اليوم والنتائج المباشرة عند توفرها، روابط البطولات والناقلين الرسميين، وتحديث كل دقيقة. لا يوجد بث فيديو ولا روابط IPTV.

## المتطلبات
- حساب Cloudflare Pages.
- رمز API من football-data.org.
- راجع خطة مزود البيانات الحالية لمعرفة البطولات وحدود الاستخدام.

## النشر
1. ارفع الملفات إلى مستودع GitHub.
2. في Cloudflare: Workers & Pages → Create application → Pages → Connect to Git.
3. اختر المستودع. اترك Build command فارغًا، واجعل Build output directory `.`.
4. بعد النشر، افتح إعدادات المشروع ثم Variables and Secrets، وأضف Secret باسم `FOOTBALL_API_TOKEN` وقيمة مفتاح API.
5. أعد النشر وافتح رابط Pages. اختبر `/api/matches?date=YYYY-MM-DD` من الموقع.

## ملاحظات
- فتح index.html محليًا مباشرة لن يعمل مع API لأن المسار `/api/matches` يُنفذ بواسطة Cloudflare Pages Function.
- لا تضع API token في ملفات الواجهة.
- بعض البطولات غير متاحة ضمن الخطط المجانية؛ النتائج وتوقيت التحديث يعتمدان على مزوّد البيانات.
- روابط الناقلين الرسمية لا تضمن توفر بث مجاني؛ حقوق البث تختلف حسب البلد والبطولة.
- المحتوى الإخباري في الواجهة تجريبي؛ أضف مقالات أصلية قبل التقديم للإعلانات.
- احذف أو بدّل أي شعارات لا تملك حق استخدامها إذا كانت شروط مزوّد البيانات لا تسمح بذلك.
